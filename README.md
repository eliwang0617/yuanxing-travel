# 远行 · 人民币旅行预算规划

公开网站：https://yuanxing-travel-261116.pearly-pika-4958.chatgpt.site

支持 18 座国内外城市的旅行费用估算、交通方式比较和按天行程。页面无需账号，数据在浏览器本地计算。

## 功能

- 出发地、目的地、日期、2–14 天、1–8 人。
- 人均／全体预算切换，经济、均衡和舒适安排。
- 往返交通、住宿、餐饮、当地交通、游玩、其他费用和 10% 预留金。
- 自填往返交通报价、每间每晚酒店均价，选择每人一间或两人一间。
- 展示中心估算和偏高花费情景，明确预算缺口。
- 行程地图检索入口、浏览器收藏、文本下载、打印 / PDF、分享链接。
- 自适应手机布局，无第三方字体或前端依赖。

## 数据限制

费用是人民币模型参数，不是实时机票、火车票、酒店行情或汇率。模型交通不保证存在直达班次。路线按片区组合，不识别当天开放、预约、天气和节假日。每个城市只提供四组精选片区，较长旅行会显式保留自由活动日。出境购物、签证、保险等可自行输入其他费用。详细公式见网页“估算说明”和 planner.mjs。

自填报价只用于当前选择的交通方式；更改城市、日期、天数或人数会清空交通报价，切换目的地会清空住宿报价。分享链接包含表单内容，公开给持有链接的人；本地收藏不自动同步。

## 开发

需要 Node.js 20 或更新版本，无需 npm install。

```sh
npm test
npm run dev
```

打开终端显示的本地网址。网站文件在 ，计算逻辑在 planner.mjs，交互在 app.mjs。

## 发布

现有公开网址使用 Sites 托管。GitHub 镜像版本将网站文件放在仓库根目录；如需 GitHub Pages，在仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)，然后 Save。发布成功后以 GitHub 设置页显示的网址为准。

## 维护

新增城市时补充坐标、明确的人民币费用参数、片区路线及官方资料链接。价格不是采样数据，调整参数后需同步网页估算说明。运行测试检查预算合计、分享恢复和所有城市组合，发布前在桌面及手机浏览器核对表单与收藏交互。
